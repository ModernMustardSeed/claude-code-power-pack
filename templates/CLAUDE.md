## Automation Boundaries

- File operations, code edits, builds, tests
- Git operations (commit, branch, local)

- Memory graph updates

**Ask first:**
- Emails, messages, anything public-facing
- Git push, PR creation, deployments
- Destructive operations (delete, force-push, reset --hard)
